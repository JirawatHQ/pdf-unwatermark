ลบลายน้ำออกจาก PDF ของคุณ โดยไฟล์ไม่ออกจากเครื่อง

สำหรับเอกสารที่คุณเป็นเจ้าของหรือมีสิทธิ์แก้ไข เช่น ไฟล์ร่างที่ใส่คำว่า "ร่าง" หรือโลโก้ไว้ทุกหน้า แล้วต้องการฉบับสะอาด ทุกขั้นทำในเบราว์เซอร์นี้

ลากไฟล์ PDF มาวางตรงนี้

เลือกได้หลายไฟล์ ไฟล์ที่ตั้งรหัสผ่านต้องปลดรหัสก่อน

    ตรวจเองได้ว่าไฟล์ไม่ถูกส่งออก

    ไฟล์ PDF ถูกอ่านและแก้ในเบราว์เซอร์ ไม่มี API สำหรับอัปโหลดไฟล์ กฎ connect-src 'none' บล็อกคำขอส่งข้อมูลแบบ fetch/XHR และสคริปต์ทั้งหมดมาจากเว็บนี้

    1. ใน Chromium ทดสอบได้โดยเปิดหน้านี้ให้โหลดเสร็จ แล้วปิด Wi-Fi หรือถอดสายเน็ตก่อนเลือกไฟล์ เบราว์เซอร์อื่นอาจจัดการไฟล์แบบออฟไลน์ต่างกัน
    2. หรือเปิดเครื่องมือนักพัฒนา (F12 หรือ ⌥⌘I) ไปแท็บ Network แล้วลากไฟล์ลง จะไม่มีคำขออัปโหลด PDF อาจเห็นคำขอโหลดไฟล์ pdf.worker.min.js จากเว็บนี้

    ลบอะไรได้ ลบอะไรไม่ได้

    • ลบได้: ลายน้ำที่ใส่เป็นวัตถุแยก (annotation หรือ layer ชื่อ Watermark), ข้อความจางที่วางซ้ำเฉียง และรูปที่วางซ้อนซ้ำเกือบทุกหน้า (ไม่นับภาพเต็มหน้า)
    • หลังลบ หน้าเว็บเทียบข้อความที่ดึงได้ทุกหน้ากับต้นฉบับ ถ้าไม่ตรงจะไม่ให้ดาวน์โหลด การตรวจนี้ไม่ครอบคลุมข้อความที่เป็นส่วนหนึ่งของภาพสแกน
    • ยังลบไม่ได้อัตโนมัติ: ลายน้ำที่พิมพ์ติดในภาพสแกน, ข้อความลายน้ำรูปแบบอื่น หรือวัตถุที่ฝังอยู่ใน Form XObject จึงไม่รับประกันว่าจะลบได้ทุกไฟล์
    • ไฟล์ที่มีลายเซ็นดิจิทัลหรือรูปแบบภาพฝังในคำสั่ง PDF ที่ตรวจไม่ได้อย่างปลอดภัยจะถูกปฏิเสธ
    • โลโก้หัวกระดาษที่อยู่ทุกหน้าอาจถูกนับเป็นรูปซ้ำ ถ้าอยากเก็บไว้ ให้เอาติ๊กชนิดนั้นออกก่อนกดลบ

    อย่าใช้ลบลายน้ำหรือตราที่เจ้าของลิขสิทธิ์หรือคลังเอกสารใส่ไว้เป็นเงื่อนไขการใช้งาน
